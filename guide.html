Guide Voxwrist Ask

Réponses courtes aux questions les plus fréquentes (volume, rappels, clés, endpoint local).

Volume de la réponse

  • Par défaut le volume est au maximum (le haut-parleur des fēnix est petit).
  • Pendant que l'assistant parle : UP / DOWN sur la montre (Doux ↔ Normal ↔ Fort).
  • Ou Garmin Connect › Applis Connect IQ › Voxwrist Ask › Réglages › Volume de la réponse.

Rappels à la voix

  • Dites par exemple : « rappelle-moi à 18 h d'appeler Paul ».
  • Réglage Rappels vocaux :
    • Sur la montre seulement (défaut) — vibration à l'heure dite.
    • Montre + e-mail calendrier (.ics) — garde le rappel local et envoie une invitation .ics à l'adresse mail des réglages (Gmail / Apple Mail l'ajoutent à l'agenda).
    • E-mail calendrier seulement (.ics) — pas de rappel sur la montre si l'e-mail part ; sinon repli sur la montre.
  • Pour l'e-mail calendrier : renseignez Votre adresse mail (et le code d'accès si vous utilisez aussi le brief mail). Le relais doit avoir l'envoi d'e-mail activé.
  • Le lien iCal du brief reste lecture seule (pas d'écriture directe Google Agenda OAuth pour l'instant).
  • Rappels courts (< ~5 min) : gardez l'app ouverte (limite Garmin en fond).
  • Maximum 8 rappels sur la montre.

Clés IA

  • Au moins une clé qui comprend la voix : Gemini, Groq ou OpenAI.
  • Pour entendre la réponse : OpenAI ou Gemini.

URL compatible OpenAI (local / privé)

  • Réglage avancé : URL compatible OpenAI, ex. http://192.168.1.10:11434/v1 (Ollama) ou votre LiteLLM / LocalAI.
  • Remplissez aussi le champ clé OpenAI (toute clé sk-… acceptée par votre serveur).
  • Le relais cloud (Vercel) ne peut joindre une IP privée chez vous : pour du 100 % local, pointez aussi le relais vers une instance sur votre réseau, ou exposez votre endpoint via un tunnel HTTPS.

Brief du jour

  • Météo : ville · Agenda : lien iCal privé (lecture) · Mails : adresse + code d'accès IMAP.

English

Short answers (volume, reminders, keys, local endpoint).

Answer volume

  • Default is maximum. UP / DOWN while speaking cycles Soft / Normal / Loud. Or set it in Connect IQ settings.

Voice reminders

  • Setting Voice reminders: watch only · watch + calendar email (.ics) · calendar email only.
  • Calendar email uses your mail address from settings; the relay must be able to send mail. Brief iCal stays read-only.
  • Short reminders (< ~5 min): keep the app open.

OpenAI-compatible URL

  • Advanced setting for Ollama / LiteLLM / LocalAI (e.g. http://192.168.1.10:11434/v1) plus an OpenAI key field your server accepts.
  • Cloud relay cannot reach your LAN: self-host the relay or use a public HTTPS tunnel to your endpoint.
