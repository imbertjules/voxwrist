# voxwrist-site

Site vitrine statique et documents Store de la marque **Voxwrist** (Notes + Ask). Aucun build : HTML et CSS seulement.

- `index.html` : page d'accueil FR/EN
- `privacy.html` : politique de confidentialité FR/EN (URL obligatoire pour le Store)
- `assets/` : icônes 500×500
- `store-screenshots/` : captures simulateur (fēnix 8 43 mm)
- `docs/STORE_LISTING.md` : textes des fiches FR/EN
- `docs/PUBLISHING.md` : étapes restantes pour publier

Hébergement gratuit : GitHub Pages, Cloudflare Pages ou Vercel (dossier racine = ce dépôt).
